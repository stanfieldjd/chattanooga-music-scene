=== CMS Mobile Landing Redirect ===
Requires at least: 6.2
Requires PHP: 8.0
Stable tag: 1.0.0

Redirects phone visitors from the Chattanooga Music Scene landing splash page
to The Scene. Desktop visitors continue to see the landing page.
