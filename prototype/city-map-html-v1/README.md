# City Map HTML Prototype v1

This directory contains the rebuildable implementation of the approved city-map direction. The reference PNG is not used as the page background. The environment, streets, buildings, signpost navigation, destination buildings, luminous route, labels, and content are independent HTML/SVG/CSS layers.

Edit current labels and homepage information in `content.js`. Edit composition, texture, color, scale, angles, and depth in `styles.css`. WordPress transfer has not started.
