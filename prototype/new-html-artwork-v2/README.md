# New HTML artwork mock-up v2

This is a new 1920 × 1080 desktop homepage artwork constructed entirely from independent HTML, CSS, SVG, text, links, and replaceable image layers. It is not a revision of the WordPress prototype and does not use a flattened full-page mock-up.

The custom display font is embedded in `index.html`. The logo is intentionally fixed except for its linked destination and neon hover behavior. Event information, navigation, calls to action, venue information, editorial content, images, colors, angles, and positions remain independently editable.

`layer-manifest.json` records the construction sequence and editability of all 16 layers.
